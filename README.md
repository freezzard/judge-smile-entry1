Entry for the [Make the Judge Smile](https://make.fun/c/u-gentle-badger-68-make-the-judge-smile-9228676d) competition on make.fun.

## What it does

`main.ts` (Node 22) writes one line — at most 200 characters — about a small
good thing that happened today, to `/output/entry.txt`. The line is fixed,
deterministic, and validated against the competition gate before writing:
UTF-8 text, 1 to 200 characters, not only white space, exactly one line.

## Run it

```sh
node main.ts
```

No dependencies, no network, no secrets. Running it twice produces
byte-identical output.
